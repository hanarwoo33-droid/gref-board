# 이번 주 자란 것들 — 설치 순서

GREF 주간 콘텐츠 소재 보드입니다. 링크만 있으면 누구나(로그인 없이) 열어서 제출할 수 있고,
제출 내용은 **잼잼님 구글 시트**에 쌓입니다.

전체 15~20분이면 끝납니다. 순서대로만 따라오세요.

---

## 1단계 · 구글 시트 만들기 (2분)

1. [sheets.new](https://sheets.new) 접속 → 빈 시트가 열립니다.
2. 이름을 `GREF 주간 소재` 정도로 바꿔주세요.
3. **시트는 그냥 비워두시면 됩니다.** 표는 스크립트가 알아서 만듭니다.

## 2단계 · 앱스스크립트 붙여넣기 (3분)

1. 그 시트에서 상단 메뉴 **확장 프로그램 → Apps Script** 클릭.
2. 열린 편집기에 있던 `function myFunction() {}` 를 **전부 지우고**,
   같이 드린 **`Code.gs` 파일 내용 전체**를 붙여넣습니다.
3. 디스크 모양(저장) 아이콘 클릭.

## 3단계 · 웹 앱으로 배포 (5분) — 가장 중요한 단계

1. 오른쪽 위 파란 **배포 → 새 배포** 클릭.
2. 왼쪽 톱니바퀴(⚙️) → **웹 앱** 선택.
3. 설정을 이렇게 맞춰주세요:
   - 설명: `GREF 보드` (아무거나)
   - **다음 사용자로 실행: 나 (본인 계정)**
   - **액세스 권한이 있는 사용자: 모든 사용자** ← 이게 핵심입니다
4. **배포** 클릭 → 권한 승인 창이 뜹니다.
   - "이 앱은 확인되지 않았습니다" 경고가 나오면
     **고급 → (프로젝트 이름)(으)로 이동 → 허용** 을 눌러주세요.
     내가 만든 내 스크립트라서 나오는 정상적인 경고입니다.
5. 마지막에 나오는 **웹 앱 URL** 을 복사합니다.
   `https://script.google.com/macros/s/.../exec` 형태입니다.

> 나중에 `Code.gs` 를 고쳤다면 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**
> 를 눌러야 반영됩니다. (주소는 그대로 유지돼요)

## 4단계 · index.html에 주소 넣기 (1분)

`index.html` 을 메모장이나 VS Code로 열고, `<script>` 시작 부분의 이 줄을 찾습니다.

```js
var CONFIG = {
  ENDPOINT: "여기에_앱스스크립트_웹앱_주소_붙여넣기"
};
```

따옴표 안을 3단계에서 복사한 주소로 바꾸고 저장합니다.

```js
var CONFIG = {
  ENDPOINT: "https://script.google.com/macros/s/AKfy...../exec"
};
```

## 5단계 · GitHub Pages에 올리기 (5분)

1. [github.com/new](https://github.com/new) 접속.
2. Repository name: `gref-board` (아무거나) / **Public** 선택 / **Create repository**.
3. 만들어진 화면에서 **uploading an existing file** 링크 클릭.
4. `index.html` 을 끌어다 놓고 아래 **Commit changes** 클릭.
5. 상단 **Settings → 왼쪽 메뉴 Pages** 이동.
6. Source: **Deploy from a branch**, Branch: **main** / **/(root)** → **Save**.
7. 1~2분 뒤 그 페이지 위쪽에 주소가 뜹니다.
   `https://<내아이디>.github.io/gref-board/`

이 주소가 매주 단톡방에 보낼 링크입니다.

## 6단계 · 확인

- 링크를 열어 아무 카드나 눌러 테스트로 한 건 제출해보세요.
- 구글 시트 `제출` 탭에 줄이 생기면 성공입니다.
- 테스트 줄은 시트에서 그 행을 지우면 됩니다.

## 알아두실 점

- **링크를 아는 사람은 누구나 읽고 쓸 수 있습니다.** 로그인이 없는 대신 그렇습니다.
  사내 단톡방에만 공유하시고, 대외비 내용은 올리지 않도록 안내해주세요.
- 제출자는 **자기가 쓴 글만** 삭제할 수 있습니다(같은 브라우저 기준).
  다른 건 잼잼님이 구글 시트에서 해당 행을 지우면 됩니다.
- 보드는 45초마다 자동으로 새 내용을 불러옵니다. 급하면 우하단 **새로고침** 버튼.
- 주차는 **월요일 시작** 기준이고 자동으로 넘어갑니다. 별도 관리 불필요.
- 지난 주 내용은 우상단 **‹** 화살표로 볼 수 있습니다.
- 시트 메뉴 **GREF 보드 → 이번 주 취합 내용 보기** 로도 정리본을 볼 수 있어요.

## 내용 고치고 싶을 때

`index.html` 안의 `DEPTS` 부분에서 분야 이름과 예시 문구를 바꿀 수 있습니다.

```js
{ id:"grow", ko:"재배", en:"Cultivation", hints:[
  "작물 생육 변화","품종별 특징", ...
]},
```

- `ko` : 카드에 보이는 분야 이름
- `hints` : 클릭하면 입력창에 자동으로 들어가는 예시 문구
- `id` 는 **바꾸지 마세요.** 시트에 저장된 기존 데이터와 연결되는 값입니다.

고친 파일을 GitHub 저장소에 다시 업로드(같은 파일명으로 덮어쓰기)하면 1~2분 뒤 반영됩니다.
